# 情報Ⅰ 冬期講習

高1・高2対象、90分×4回。生徒用ページは `index.html`、教員用進行表は `teacher-guide.html`。

| 回 | 内容 |
|---|---|
| 1 | 表・割合・散布図と根拠の説明 |
| 2 | 通信速度・単位換算・複数条件での判断 |
| 3 | 条件分岐・繰り返し・変数の追跡 |
| 4 | 配列・最大値・同値の場合の更新 |

## 使い方

1. 生徒は答えを開く前にノートで予想と理由を書く。
2. プログラミング問題はラボでステップ実行し、変数と履歴を確認する。
3. 設定を変えて再実行し、予想との差を説明する。

`winter` フォルダ一式をダウンロードすれば、`index.html` をブラウザで開いて利用できます。外部APIやアカウント登録は不要です。学習記録の永続保存機能はありません。ラボは収録6題専用で、任意のDNCLコードを実行するものではありません。

教員用進行表はブラウザで印刷できます。
