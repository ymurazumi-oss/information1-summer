第1回　基礎・データ活用

どの数字を見て、そう言える？

下の表は、体験講座の参加者とアンケートの回答数をまとめたものです。数値は練習用です。

基本問題　人数と割合を比べる

体験講座のアンケート
講座参加者回答者「また参加したい」と答えた人数
A40人30人24人
B30人20人18人
C20人20人16人
  1. 「また参加したい」と答えた人数が最も多いのはどの講座？
  2. 回答者に占める「また参加したい」の割合が最も高いのは？ どの数字で割ったかも書こう。
  3. 友達が「参加者全体で見てもBが一番だね」と言った。表の数字を使って返事をしよう。
答えと考え方

1．Aの24人。2．Bの18÷20＝90％。AとCは80％。3．参加者全体のうち「そう答えた」割合なら、Aは60％、Bは60％、Cは80％。未回答の人がどう思っていたかは、この表からは分からない。

挑戦問題　グラフからどこまで言える？

体験講座を開いた6日間について、その日の気温と冷たい飲み物の販売数を記録した。

  1. 「気温が高い日はよく売れる傾向がある」と「気温が高い日は必ず多く売れる」のうち、グラフに合うのはどちら？
  2. 売れた理由まで確かめるなら、気温と販売数のほかに何を記録する？
答えと考え方

1．前者。全体では右上がりの傾向だが、22℃より24℃の日の方が販売数は少ない。2．たとえば来場者数。来場者が多い日ほど売れやすいと考えられるので、販売数だけでなく来場者100人当たりの販売数も比べられる。

第2回　基礎・データ活用

この条件なら、どの送り方？

データを送るときは、サイズと時間の単位をそろえる。最後に、計算以外の条件も見直そう。

基本問題　校内発表の動画を送る

締切まで90秒。回線は毎秒8メガビット（8 Mb/s）で一定とする。準備時間も含めて90秒以内に送り終えたい。映像内の文字が読めることも必要。1 MB＝8 Mbとし、表にない時間は考えない。

送信するファイルの候補
候補サイズ準備時間映像内の文字
A　元の動画120 MB0秒読める
B　圧縮版60 MB20秒読める
C　強く圧縮した版36 MB10秒読めない
  1. それぞれ送信に何秒かかる？ 準備も含めた時間を書こう。
  2. どれを送る？ 選ばなかった二つについても理由を書こう。
  3. すでにBの圧縮が終わっていて、残り時間が70秒なら、Bを送り終えられる？
答えと考え方

1．8 Mb/sは1 MB/sなので、送信だけならAは120秒、Bは60秒、Cは36秒。準備込みでは120秒、80秒、46秒。2．B。Aは90秒を超え、Cは文字が読めない。3．送信だけで60秒なので間に合う。

挑戦問題　途中で回線が遅くなる

Bの準備は20秒。送信を始めてから最初の30秒は8 Mb/s、その後は4 Mb/sだった。締切まで90秒あるとき、この回線で間に合う？ 残りを送るには、後半に最低何 Mb/s必要？

答えと考え方

最初の30秒で30 MB送れる。残り30 MBを4 Mb/s（0.5 MB/s）で送ると60秒かかり、準備から合計110秒。残り時間は90−20−30＝40秒なので、必要な速度は240 Mb÷40秒＝6 Mb/s。

早く終わったら　元の動画を送りたい

Aの元の動画（120 MB）を圧縮せず、90秒以内に送りたい。回線は最低何 Mb/s 必要？ 小数第1位までの速度から選ぶとしたら、いくつにする？

答えと考え方

120×8÷90＝32/3 Mb/s（約10.67 Mb/s）。小数第1位までなら10.7 Mb/s。10.6 Mb/sでは90秒以内に送り終わらない。

第3回　プログラミング

次の1行で、値はどう変わる？

最初は手で追う。予想を書いてから、ラボの「ステップ実行」を1回ずつ押そう。ラボを開いたら、画面上の「問題に戻る」でこの問題に戻れます。

ウォームアップ　境目の点数

60点以上を合格にする。59点、60点、61点で何が表示される？ ラボで点数を変えて確かめよう。

ラボを開く　合否判定
答えと考え方

59点は不合格、60点と61点は合格。「以上」には60点を含む。

基本問題　1から5まで足す

goukei = 0
i を 1 から 5 まで 1 ずつ増やしながら繰り返す:
    goukei = goukei + i
表示する(goukei)
  1. i が1、2、3、4、5のとき、それぞれ足し算をした直後の goukei を書こう。
  2. 最初の goukei を10に変えると、最後に何が表示される？ 確かめる前に理由も書こう。
ラボを開く　1からnの合計
答えと考え方

1．1、3、6、10、15。2．25。足す数は同じで、出発点だけが10増える。

挑戦問題　5の倍数だけ足す

1から20まで調べる。5で割った余りが0のときだけ足すと、どの数を足す？ 条件を「余りが0ではない」に変えると合計はいくつ？

ラボを開く　倍数だけ合計
答えと考え方

5、10、15、20を足すので50。条件を逆にすると、1から20までの合計210から50を引いて160。

第4回　プログラミング

いちばん大きい値を、どこで見つけた？

ウォームアップ　添字は0から

Data = [6, 3, 8, 4] のとき、Data[0] と Data[2] はいくつ？ i を0から3まで動かし、(i, Data[i]) を表示すると、どの順になる？

ラボを開く　すべて表示
答えと考え方

Data[0] は6、Data[2] は8。表示は (0, 6)、(1, 3)、(2, 8)、(3, 4) の順。

基本問題　最大値と位置を覚えておく

Data = [5, 9, 4, 12, 7]
saidai = Data[0]
ichi = 0
i を 1 から 4 まで 1 ずつ増やしながら繰り返す:
    もし Data[i] > saidai ならば:
        saidai = Data[i]
        ichi = i
表示する(saidai, ichi)
  1. i が1、2、3、4のとき、処理後の (saidai, ichi) を順に書こう。
  2. 最後に表示される値と、その値が配列の何番目にあるかを答えよう。
ラボを開く　最大値と位置
答えと考え方

1．(9, 1)、(9, 1)、(12, 3)、(12, 3)。2．表示は (12, 3)。添字3は先頭から4番目。

挑戦問題　最大値が二つあったら？

Data = [9, 4, 9, 7] で、最大値と位置を調べる。「>」で比べる場合と「>=」で比べる場合、それぞれ最後の ichi はいくつ？ 違いが出る回を探そう。

ラボを開く　同じ最大値
答えと考え方

「>」なら0、「>=」なら2。i が2のとき、同じ9を見て位置を更新するかどうかが違う。

次は夏期講習で　何分待つ？

体験コーナーでは、1人につき4分かかる。開始から0分、4分、5分の時点で1人ずつ来た。前の人が終わり次第、次の人が始められる。3人目は何分待つ？ どの人の終了時刻を見ればいいだろう。

答えと考え方

3分。2人目は開始から8分の時点で終わる。3人目は5分の時点に来て、8分の時点で始められる。
